# Project Name

## Overview
A web-based e-commerce management system developed using PHP and MySQL. The system allows users to browse products, place orders, and manage their profiles, while administrators can manage products, orders, users, and customer inquiries through a dedicated admin panel.

## Features

### User Features
- User Registration and Login
- Browse Products
- Search Products
- Add Products to Cart
- Place Orders
- Manage User Profile
- Contact Administration

### Admin Features
- Dashboard Overview
- Product Management (CRUD)
- Order Management
- User Management
- Contact Message Management
- Profile Management

## Technology Stack

### Frontend
- HTML5
- CSS3
- JavaScript

### Backend
- PHP

### Database
- MySQL
